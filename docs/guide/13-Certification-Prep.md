# Certification Prep: Service Cloud Consultant

## Overview

The Salesforce Certified Service Cloud Consultant exam validates your ability to design and implement Service Cloud solutions that meet business requirements. This guide provides the most current exam facts, a comprehensive study plan, domain breakdown, and strategies for tackling the scenario-based questions that dominate the exam.

This guide is your final preparation resource before taking the Salesforce Certified Service Cloud Consultant (CRT-150 / SC2) exam.

## Exam Facts

### Current Exam Structure

| Detail | Value |
|--------|-------|
| Exam Name | Salesforce Certified Agentforce Service Consultant (formerly Service Cloud Consultant) |
| Exam Code | CRT-150 (SC2) |
| Number of Questions | 60 scored + up to 5 unscored |
| Time Limit | 105 minutes |
| Passing Score | 78% (English); 67% (Japanese) |
| Exam Fee | $200 (plus applicable taxes) |
| Retake Fee | $100 (plus applicable taxes) |
| Prerequisite | Salesforce Certified Platform Administrator |
| Format | Multiple choice, multiple-select, scenario-based |
| Delivery | Online proctored or in-person test center |

### Exam Domains and Weights

As of Spring '26, Case Management alone is 32% of the exam — master it first. Combined, the top three sections (Case Management, Service Cloud Platform, Interaction Channels) are 56%.

| Domain | Weight | Focus Areas |
|--------|--------|-------------|
| Case Management | 32% | Case lifecycle, queues, assignment rules, escalation rules, auto-response rules, case teams, email-to-case, web-to-case |
| Service Cloud Platform | 13% | Service Cloud configuration, Lightning console apps, macros, quick text, Einstein features, entitlements & milestones |
| Interaction Channels | 11% | Email-to-case, web-to-case, live chat, messaging, voice (CTI), social customer service, self-service portals |
| Knowledge Management | 10% | Knowledge article types, data categories, article visibility, Knowledge in Service Console, Lightning Knowledge |
| Contact Center Analytics | 9% | Case reports, service dashboards, SLA adherence reporting, agent productivity metrics |
| Service Cloud Solution Design | 9% | Gathering requirements, matching business needs to features, ROI and business case scenarios |
| Integrations and Data Management | 8% | CTI integration, third-party telephony, data migration for cases/contacts, external data sources |
| Service Console | 8% | Console navigation, split view, workspace tabs, subtabs, macros, keyboard shortcuts, utility bar |

### Question Types

| Type | Description | Strategy |
|------|-------------|----------|
| Multiple Choice | Single correct answer | Eliminate wrong answers |
| Multiple Select | 2+ correct answers | Answer only options you're certain about |
| Scenario-Based | Business context + solution | Match solution to requirements |

## Tips for Scenario-Based Questions

### Scenario Analysis Framework

**Read the scenario carefully and identify:**

1. **Business requirements**: What is the customer trying to accomplish?
2. **Constraints**: What limitations exist (licenses, editions, budget)?
3. **Pain points**: What problems is the current system causing?
4. **Success criteria**: What does success look like?
5. **Architectural debt**: What existing systems must be preserved?

**Analyze answer choices:**

1. Does the answer address ALL the requirements?
2. Does the answer respect ALL the constraints?
3. Does the answer address the ROOT cause or just a symptom?
4. Is the answer the most EFFICIENT use of the platform?
5. Does the answer align with Salesforce best practices?

### Common Scenario Patterns

| Pattern | Best Answer Strategy |
|---------|---------------------|
| High case volume | Recommend Omni-Channel + automation |
| SLA compliance issues | Recommend entitlements + milestones |
| Agent productivity | Recommend console + macros + quick text |
| Knowledge gaps | Recommend Knowledge + article suggestions |
| Multi-channel support | Recommend unified channel configuration |
| Data migration | Recommend phased migration + validation |
| Integration needs | Recommend API-based solutions |

### Speed Reading Technique

1. **Read the last paragraph first** (question stem)
2. **Scan scenario for constraints** (editions, licenses, numbers)
3. **Identify the decision point** (what action is required)
4. **Evaluate each answer** against requirements
5. **Eliminate impossible answers** (license/schema violations)
6. **Choose the BEST fit** (not just a valid answer)

## Exam-Taking Strategies

| Strategy | Description |
|----------|-------------|
| Time Management | ~1.5 minutes per question, save time for review |
| Flagging | Flag uncertain questions and return later |
| Process of Elimination | Eliminate obvious wrong answers first |
| Don't Overthink | Your first instinct is usually correct |
| Watch for Traps | Similar-sounding but different options |
| Manage Fatigue | Take structured breaks if needed |

### Before the Exam

1. Confirm the exam date, time, and location
2. Test your environment (online proctoring)
3. Have a quiet, well-lit space
4. Keep water and snacks nearby
5. Get a good night's sleep
6. Arrive 15-30 minutes early

### During the Exam

1. Read every question carefully
2. Look for "NOT" and "EXCEPT" keywords
3. Consider all requirements before answering
4. Use process of elimination
5. Flag difficult questions and return later
6. Save at least 15 minutes for review

## Common Exam Traps

- **Trap**: Choosing the "possible" answer instead of the "best" answer.
- **Trap**: Missing "NOT" or "EXCEPT" in the question stem.
- **Trap**: Selecting answers that violate license or edition constraints.
- **Trap**: Choosing answers that solve one problem but create another.
- **Trap**: Rushing through scenario questions without reading closely.
- **Trap**: Forgetting that hardware/appliance solutions are not the best fit for cloud-first customers.
- **Trap**: Assuming all integration tools are interchangeable — REST API vs. Flow vs. Connect-Custom tools have distinct uses.
